# Ledger

Простой сервис учёта финансовых транзакций с поддержкой бюджетов по категориям.

## Возможности

- добавление финансовых транзакций;
- установка бюджета для категории;
- изменение существующего бюджета;
- проверка лимита бюджета при добавлении транзакции;
- отклонение транзакций, превышающих бюджет;
- загрузка бюджетов из JSON;
- обработка ошибок;
- unit-тесты.
